# Entwicklungsstand 0.5.3 / 0.6

## 0.5.3 – automatische Synchronisation und Erinnerungen

Umgesetzt:

- zentrale Worker-/SMTP-Konfiguration in `config.py`
- automatischer CalDAV-Sync über `calendar_sync_worker.py`
- systemd One-Shot-Service und 5-Minuten-Timer für CalDAV
- persistenter Reminder-Status über `JobDelivery`
- Migration `0008_worker_state.py`
- Retry-Felder über Migration `0009_reminder_retries.py`
- Reminder-Queue über `reminder_queue_worker.py`
- SMTP-Komponente über `smtp_mailer.py`
- Reminder-Queue und SMTP-Zustellung laufen gemeinsam über einen systemd One-Shot-Service
- Reminder-Timer läuft jede Minute
- Debian-Installer installiert und aktiviert die Timer automatisch

Konfiguration:

- `FAMILIENPORTAL_WORKER_INTERVAL_SECONDS`
- `FAMILIENPORTAL_CALENDAR_SYNC_INTERVAL_MINUTES`
- `FAMILIENPORTAL_SMTP_HOST`
- `FAMILIENPORTAL_SMTP_PORT`
- `FAMILIENPORTAL_SMTP_USERNAME`
- `FAMILIENPORTAL_SMTP_PASSWORD`
- `FAMILIENPORTAL_SMTP_FROM`
- `FAMILIENPORTAL_SMTP_STARTTLS`

## 0.6 – Mailcow

Umgesetzt:

- `MailcowClient` mit API-Key-Authentifizierung
- Domains lesen
- Postfächer lesen
- Aliase lesen
- Quota-Summen ermitteln
- API-Healthcheck
- Mailcow-Statusseite `/platform/mailcow`
- Router in `main.py` registriert
- Mailcow-Capabilities im Systemendpunkt
- API-Key bleibt als Environment-Secret referenziert und wird nicht als Klartext in der Datenbank gespeichert
- Beispielvariable `FAMILIENPORTAL_MAILCOW_API_KEY` in `.env.example`

Noch offen für 0.6.x:

- komfortable eigene Mailcow-Konfigurationsmaske für die Secret-Referenz
- schreibende Verwaltung für Postfächer
- schreibende Verwaltung für Aliase und Verteiler
- Quota-Änderungen
- Webmail/SOGo-Verknüpfung pro Benutzer
- Benutzer-Mapping Portal ↔ Mailcow

## Debian-Betrieb

Nach einem Update:

```bash
cd /opt/familienportal
sudo -u familienportal .venv/bin/alembic upgrade head
sudo systemctl daemon-reload
sudo systemctl enable --now familienportal-calendar-sync.timer
sudo systemctl enable --now familienportal-reminder-queue.timer
sudo systemctl restart familienportal
```

Timer prüfen:

```bash
systemctl list-timers 'familienportal-*'
```
